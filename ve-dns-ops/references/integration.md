# Integration

## Go SDK Package

| Service | Package |
|---------|---------|
| DNS | `github.com/volcengine/volc-sdk-golang/service/dns` |

## Cross-Service

- **CDN:** CNAME records point to CDN domains
- **CLB:** A records point to load balancer IPs
- **ECS:** A records point to ECS public IPs
- **Certificate:** TXT records for domain verification
