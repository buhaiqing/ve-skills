# DNS Core Concepts

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Domain/Zone** | A managed DNS zone for a domain name |
| **Record Set** | DNS resource record (A, CNAME, MX, TXT, NS, AAAA) |
| **TTL** | Time-to-live for DNS record caching |
| **Resolution Policy** | Geo-based or weighted routing policies |
| **DNS Security** | DDoS protection, DNSSEC support |

## Record Types

| Type | Use Case |
|------|----------|
| A | Map domain to IPv4 address |
| AAAA | Map domain to IPv6 address |
| CNAME | Alias to another domain |
| MX | Mail server routing |
| TXT | Verification, SPF, DKIM |
| NS | Name server delegation |
