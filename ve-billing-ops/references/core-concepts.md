# Billing Core Concepts

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Bill** | ℹ️ Monthly statement of resource usage and cost |
| **Budget** | ℹ️ Spending limit with alert thresholds |
| **Reserved Instance** | ℹ️ Pre-purchased capacity for discount |
| **Cost Tag** | ℹ️ Tag-based cost allocation and grouping |
| **Balance** | ℹ️ Account prepaid balance |

## Cost Types

- **Pay-as-you-go (PostPaid):** 💰 Pay per usage
- **Subscription (PrePaid):** 💰 Pre-pay for period
- **Reserved Instance:** 💰 Upfront payment for discounted rate
