# Billing Core Concepts

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Bill** | Monthly statement of resource usage and cost |
| **Budget** | Spending limit with alert thresholds |
| **Reserved Instance** | Pre-purchased capacity for discount |
| **Cost Tag** | Tag-based cost allocation and grouping |
| **Balance** | Account prepaid balance |

## Cost Types

- **Pay-as-you-go (PostPaid):** Pay per usage
- **Subscription (PrePaid):** Pre-pay for period
- **Reserved Instance:** Upfront payment for discounted rate
