# Ark Core Concepts

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Endpoint** | Inference API endpoint for model serving |
| **Model** | Pre-trained or fine-tuned LLM |
| **Training Job** | Fine-tuning task with dataset |
| **Dataset** | Training/evaluation data |
| **Model Marketplace** | Public and private model repository |

## Popular Models

| Model | Description |
|-------|-------------|
| Doubao-Pro | High-performance LLM |
| Doubao-Lite | Lightweight, fast inference |
| DeepSeek-R1 | Deep reasoning model |
| Qwen-Plus | General purpose LLM |
| Llama-3 | Open-source LLM series |
